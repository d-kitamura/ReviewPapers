# ReviewPapers

学生の学会原稿・卒業論文などの PDF を画面上で確認し、クリックした位置にコメントを付け、
コメント一覧と番号ピン付き原稿を1つの添削結果 PDF として発行するデスクトップツールです。

チェックリスト・採点・ルーブリック機能はありません。元の PDF は変更せず、コメントは JSON に
自動保存し、発行時に新しい PDF を生成します。

## 起動

```powershell
pixi install
pixi run gui
```

初回起動時に、査読対象PDFを直接入れたフォルダを選びます。選んだ場所は `.review_root` に記録されます。
環境変数 `PAPERS_REVIEW_ROOT` でも指定できます。

## フォルダ構成

```text
{査読対象フォルダ}/
  山田太郎_卒業論文_v1.pdf
  山田太郎_卒業論文_v2.pdf
  鈴木花子_学会原稿.pdf
  review_results/          # コメント記録（自動生成）
  返却/                    # 添削結果 PDF（自動生成）
```

フォルダ直下にあるPDFだけが一覧に表示されます。同じ学生の別バージョンも、ファイル名が異なれば
別々の原稿として切り替えられます。PDFのファイル名全体がコメント記録のIDになるため、添削開始後は
ファイル名を変更しないでください。

## 操作

1. 上部の原稿一覧でPDFを切り替えます。
2. PDF 上の指摘位置をクリックし、コメントを入力して「保存」します。
3. コメント入力ウィンドウは枠や角をドラッグして自由に拡大できます。入力欄も追従します。
4. 入力欄と数式プレビューの境界もドラッグでき、TeX数式を表示状態で確認できます。
5. 「align*挿入」を押すと、カーソル位置へ3行の `align*` テンプレートを挿入できます。
6. 「コメント一覧表示」から既存コメントをダブルクリックすると、編集・削除できます。
7. 「添削結果PDF発行（未発行のみ）」で、更新された原稿の結果 PDF を発行します。

コメントは保存操作のたびに `review_results/{原稿ID}.json` へ保存されます。発行される PDF は、
先頭にコメント一覧、続いて元原稿と黄色い番号ピンを収録し、相互に移動できる内部リンクを持ちます。
番号ピンの黄色背景は半透明です。コメント本文をクリックするとピンの少し上へ、ピンをクリックすると
対応するコメント見出しの少し上へ移動するため、対象が画面上端で見切れません。コピー用TeXソースの
グレー領域はリンク範囲外で、ドラッグ選択しても原稿へ移動しません。

## TeX数式コメント

コメントでは、`$...$` のインライン数式と `align` / `align*` 環境を使用できます。

```tex
ここで，$\bm{x}_{ij}=\bm{A}_i\bm{s}_{ij}$である．

\begin{align*}
\bm{x}_{ij} &= \bm{A}_i\bm{s}_{ij},\\
\mathbb{E}[\bm{x}] &= \bm{0}.
\end{align*}
```

アプリは固定プリアンブルとして `amsmath`、`amssymb`、`bm` を読み込みます。コメント内での
`\usepackage`、`\input`、`\include`、コマンド定義などは使用できません。結果PDFには組版済みの
数式と、学生が選択・コピーできるTeXソースの両方が載ります。

数式処理にはPixi環境内のTectonicを使用します。初めて数式を表示するときだけ、TeXサポート
ファイルの取得に数分かかることがあります。2回目以降はキャッシュされます。TeXエラーがある
コメントも原文のまま保存でき、PDF発行時はエラーを表示して他のコメントの処理を続行します。

## 再発行

発行済みPDFを削除しただけでは再発行対象になりません。既存コメントを開き、内容を変更せずに
「保存」すると更新日時が新しくなり、「添削結果PDF発行（未発行のみ）」から再発行できます。

## ダミーデータ

```powershell

$env:PAPERS_REVIEW_ROOT = "$PWD\fixtures\dev_root"
pixi run gui
```
